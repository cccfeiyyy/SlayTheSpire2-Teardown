## 三个核心结论

**一、可控随机：随机性只负责出题，不负责判卷。**
获取（牌、遗物、路线、事件）全随机，但战斗中敌人意图完全公开、能量与手牌完全确定。玩家每回合面对的不是赌博，而是「在已知约束下求最优解」的谜题。紧张感来自「资源永远不够花」（3 点能量对 5+ 张手牌），而不是「不知道会发生什么」——这是肉鸽公平感的来源。

**二、三大约束把「出牌」从执行变成决策。**

| 约束 | 内容 | 制造的决策 |
|---|---|---|
| 能量约束 | 3 点能量，手牌 5+ 张，无法全打 | 每张牌都有机会成本 |
| 手牌约束 | 抽牌随机，核心卡可能沉底 | 为最差情况做冗余设计 |
| 状态约束 | 敌人意图、Buff/Debuff 动态变化 | 同一张牌在不同局面价值不同 |

在此之上，每回合实际是三连判断：是否会被打死（生存）→ 能否直接击杀（终结）→ 回合交换趋势（运营）。

**三、平衡的对象是期望与方差，不是单卡强度。**

```
TurnValue = E[ Draw × PlayableRatio × AvgCardValue × Synergy ]
```

抽牌随机性决定方差，构筑决定期望，遗物与药水负责修正。这解释了两个反直觉设计：为什么「删卡」和「加卡」同样重要（卡组越小，核心卡命中率越高）；为什么过牌 / 弃牌类卡的价值被系统性抬高（它们本质是概率修正器）。
